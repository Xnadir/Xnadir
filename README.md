### 🚀 About me

- 🛠️ I build **developer tools and AI agent tooling**, and I fix bugs in open-source projects.
- 🔍 Most of my fixes are parser and edge-case bugs I find by reading code. Each one ships with a test that fails without the fix.
- 🤖 I work with **Claude Code** and say so in every PR. I review and test everything I submit.
- 🌱 Currently: contributing regularly to **[Tabularis](https://github.com/TabularisDB/tabularis)**, an open-source database client.
